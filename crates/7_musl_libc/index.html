Rust + C Calculator Demo

Example 7: Musl libc

This is a simple demonstration of how to compile Rust and C together in the same WASM binary, and make them call each other.

The C side of this example has a whole C standard library behind it. Musl v1.2.6 is compiled for wasm32-unknown-unknown by 3rd-party/wasm32-libc, so the calculator can call snprintf to format a result and printf to write a line out.

malloc and free forward to Rust's global allocator, so C and Rust share one heap that grows with the WASM memory. The single number behind store() lives in a block C asked for and Rust handed out.

Anything C prints leaves the module through one import, env.__wasm32_libc_write, and pkg/env.js forwards it to the browser console. The last call on this page, calculator.log_result(42), writes a line that way. Open the developer console to see it.
