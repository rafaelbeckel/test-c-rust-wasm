Rust + C Compression Demo

Example 9: Capstone, zlib

This is a real external C library running in a WASM binary next to Rust. The zlib sources are a git submodule, taken from upstream and compiled as they are. No patches, no shims, no per-function stubs. The build script hands eleven .c files to the cc crate and points the include path at the musl headers from 3rd-party/wasm32-libc.

That is the whole point of the eight examples before it. Once the C standard library is real, a C library written for a desktop or a server compiles for wasm32-unknown-unknown without being told it is in a browser. zlib allocates with malloc, which forwards to Rust's global allocator, so the compression buffers and the Rust Vec that receives them live on the same heap.

Rust wraps compress and uncompress in a safe Compressor, and wasm-bindgen exports it. Bytes cross as Uint8Array. Decompression takes the original length as well, because a raw zlib stream does not record it.

Built with wasm-pack
