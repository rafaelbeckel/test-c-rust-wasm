Rust + C++ Calculator Demo

Example 8: LLVM libc++

This is a simple demonstration of how to compile Rust and C++ together in the same WASM binary, and make them call each other.

The calculator here is a C++ class. It keeps its history in a std::vector and builds its label with a std::string, which means a real C++ standard library is running inside the module. LLVM's libc++ is compiled for wasm32-unknown-unknown by 3rd-party/wasm32-libcxx, on top of the musl libc from example 7. The rest of the libc++ headers, <algorithm> among them, sit on the include path next to those two.

Rust cannot call a C++ method directly, so src/calculator.cpp wraps the class in a handful of extern "C" functions over an opaque handle. That C API is what the Rust FFI declares, and wasm-bindgen exports a Rust struct around it. Arithmetic goes the other way too: subtract and multiply in the C++ class call Rust.

The module imports env.__wasm32_libc_write and pkg/env.js forwards it to the browser console. Nothing on this page writes through it. It is there because libc++ reports a failed assertion or a call to std::terminate on stderr before it aborts, and that report needs somewhere to go. setMemory still has to run first, so the shim has memory to read the message out of.

Built with wasm-pack
