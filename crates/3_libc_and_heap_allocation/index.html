Rust + C Calculator Demo

Example 3: libc and heap allocation

This is a simple demonstration of how to compile Rust and C together in the same WASM binary, and make them call each other.

The calculator stores a number on the heap from C. It links the wasm32-libc crate statically, so malloc and free live inside the module and the binary imports nothing from the host.

Those two are written in Rust and hand every C allocation to Rust's global allocator, so C and Rust share one heap that grows the WebAssembly memory as needed.
